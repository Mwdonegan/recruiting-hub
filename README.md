# Recruiting Hub

A GitHub Pages-based recruitment tracking and management platform.

## Overview

Recruiting Hub is designed to centralize recruitment processes, track candidates, and manage the hiring pipeline efficiently.

## Project Structure

```
recruiting-hub/
├─ index.html                    # Main landing page
├─ README.md                     # This file
├─ assets/
│  ├─ images/                    # Image assets
│  ├─ pdf/                       # PDF documents
│  └─ video/                     # Video files
├─ css/
│  └─ styles.css                 # Stylesheet
├─ js/
│  └─ app.js                     # Main application logic
├─ data/
│  └─ autumn-profile.json        # Profile data
└─ tracker/
   └─ recruiting-tracker.xlsx    # Recruitment tracking spreadsheet
```

## Features

- Candidate profile management
- Recruitment pipeline tracking
- Document and resource organization
- Responsive web interface

## Getting Started

1. Clone the repository
2. Navigate to the project directory
3. Open `index.html` in your browser
4. Or deploy to GitHub Pages through repository settings

## File Descriptions

- **index.html** - Main entry point for the website
- **css/styles.css** - All styling and layout rules
- **js/app.js** - JavaScript for interactivity and functionality
- **data/autumn-profile.json** - Candidate/profile information in JSON format
- **assets/** - Static resources (images, PDFs, videos)
- **tracker/recruiting-tracker.xlsx** - Spreadsheet for tracking recruitment metrics

## Development

To modify the site:
1. Edit HTML in `index.html`
2. Update styles in `css/styles.css`
3. Add functionality in `js/app.js`
4. Manage data in `data/autumn-profile.json`

## Deployment

This site is designed for GitHub Pages. Enable it in your repository settings:
1. Go to Settings → Pages
2. Select source: Deploy from a branch
3. Select branch: main (or your default branch)
4. Your site will be available at `https://mwdonegan.github.io/recruiting-hub/`
